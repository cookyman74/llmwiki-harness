## [BLOCKER]

1. 위치: `tools/llmwiki-mcp/src/vault.ts:94-95`, `.claude/skills/wiki-lint/scripts/scope-expand.py:106`, `search.py:54,71`

문제: `pyLower()`가 JS `toLowerCase()`에 의존해 Python 3.12의 `str.lower()`와 Unicode 버전 차이가 난다.

근거:

- Node 24.18/ICU 78: `U+1C89.lower() → U+1C8A`
- Python 3.12.2: `U+1C89.lower() → U+1C89`
- `U+10D50`도 Node는 `U+10D70`으로 변환하지만 Python은 유지한다.

따라서 텍스트가 `U+1C8A`, 질의가 `U+1C89`이면 Python은 미매치, TS는 매치한다. 미매치 메시지 자체도 바이트가 달라진다. 현재 픽스처와 단위 테스트는 `ΣΑΣ`, `İ`, `ǅ`만 검증한다(`p1-rows-4-9-12-15-17b-21.test.ts:69-74`).

제안: Python 3.12 기준 lower 매핑을 고정한 테이블/호환 계층을 도입하고, 위 코드포인트를 포함한 Python 실행값 테스트를 추가하라. 최소한 CI의 Node/Python Unicode 버전 차이를 명시적으로 검출해야 한다.
